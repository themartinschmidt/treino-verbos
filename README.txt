PWA INSTALLATION

1. ZIP entpacken.
2. Alle Dateien gemeinsam auf einen HTTPS-Webserver hochladen.
3. URL in Chrome auf Android öffnen.
4. Chrome-Menü > App installieren.

Hinweis: Über eine lokale file://-Adresse lässt sich eine PWA nicht vollständig installieren. Nach dem ersten Online-Aufruf funktioniert sie offline.
